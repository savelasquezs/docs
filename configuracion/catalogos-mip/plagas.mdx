## Campos de una plaga

| Campo | Requerido | Uso |
| --- | --- | --- |
| **Nombre** | Sí | Nombre con el que identificarás la plaga. |
| **Monitoreo con trampas** | Sí | Define qué tipo de trampa permite monitorear la plaga: Rastreros o Voladores. |
| **Categoría para productos** | Sí | Define qué tipo de producto se utiliza para controlar la plaga. |
| **Estado** | Automático | Determina si puede utilizarse en nuevas selecciones. |

## Entender las dos clasificaciones

**Monitoreo con trampas** y **Categoría para productos** no significan lo mismo.

### Monitoreo con trampas

Indica con qué grupo de trampas puede monitorearse la plaga:

- **Rastreros**
- **Voladores**

Por ejemplo, un roedor pertenece a **Rastreros** porque se monitorea con trampas de ese grupo.

### Categoría para productos

Indica qué productos pueden controlarla:

- **Insectos rastreros**
- **Insectos voladores**
- **Roedores**

<Warning>
  Un roedor puede pertenecer a **Rastreros** en monitoreo y a **Roedores** en productos. No es una contradicción: son dos clasificaciones con propósitos diferentes.
</Warning>

### Cuando seleccionas Voladores

Si eliges **Voladores**, el sistema asigna automáticamente **Insectos voladores** como categoría para productos.

- **Insectos rastreros**

## Diferencia entre desactivar y eliminar

| Acción | Resultado | Historial |
| --- | --- | --- |
| **Desactivar** | La plaga deja de ofrecerse para nuevas selecciones y pasa a **Inactivas**. | Se conserva. |
| **Reactivar** | Devuelve la plaga a **Activas**. | Se conserva. |
| **Eliminar** | Retira definitivamente una plaga sin relaciones ni historial. | Solo es posible cuando no existe información que proteger. |

## Validaciones y problemas frecuentes

### Falta la categoría para productos

Si seleccionas **Rastreros**, también debes elegir **Insectos rastreros** o **Roedores**. El formulario muestra **“Selecciona la categoría de producto.”**

### ¿Por qué Voladores no me deja elegir otra categoría?

Porque las plagas de monitoreo **Voladores** pertenecen automáticamente a **Insectos voladores** para productos.

### No puedo eliminar una plaga

Si tiene relaciones o historial, el sistema conserva su identidad. Utiliza **Desactivar**.
